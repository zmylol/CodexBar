## 今日新增文章摘要

摘要随安全文件读取进入现有内存快照，文章身份仍为路径，收录日期和未查看逻辑不变。采集后补写或修改摘要会更新内容，不会使已经清除的数字重新出现。文章行保留原点击与键盘动作；辅助功能名称为标题，值为完整摘要。正文使用较小字号与足够对比度，完整换行显示。

## 原 VS Code 悬停版范围

- 识别工作目录或其上级的 `.obsidian`，复用现有 VS Code IPC 订阅，不增加 Hook 或全库扫描。
- 仅汇总已收到且成功完成的 `fileChange`，支持新增、更新、移动、删除；显示每篇笔记最近一次记录的差异。
- 回看对应具体版本，独立于任务状态和已读状态。关闭预览不清空；同一笔记出现新版本会重新待回看。
- 打开现存的知识库内笔记使用 Obsidian URI；返回 Codex 复用原有 VS Code 窗口激活逻辑。
